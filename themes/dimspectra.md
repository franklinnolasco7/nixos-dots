## Color Palette

| Role                                       | Hex                               | Preview                |
| ------------------------------------------ | --------------------------------- | ---------------------- |
| Background                                 | `#101010`                         | dark neutral           |
| Foreground                                 | `#B8B8B8`                         | muted light gray       |
| Comment                                    | `#5C6370`                         | desaturated blue-gray  |
| Identifier                                 | `#BFC7D5`                         | soft blue-white        |
| Keyword / Statement                        | `#C678DD`                         | muted purple           |
| Function                                   | `#61AFEF`                         | muted blue             |
| String / Char                              | `#98C379`                         | muted green            |
| Type                                       | `#E5C07B`                         | muted yellow           |
| Special / Match-brace                      | `#56B6C2`                         | muted cyan             |
| Constant / Number                          | `#D19A66`                         | muted orange           |
| Error / Preproc / Diff-deleted             | `#E06C75`                         | muted red              |
| Highlight (search/accent)                  | `#61AFEF`                         | blue                   |
| UI chrome (line numbers, dividers, tabbar) | `#5C6370` / `#3A3A3A` / `#232323` | desaturated gray steps |
